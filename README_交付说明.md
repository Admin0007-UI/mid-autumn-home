# 月下 · 中秋手机首页 v4.0

2026-10-29 · finesse-ui · 结合两张用户参考的图文精修

## 主要变化

保留第三版的显性搜索、八项服务入口、底栏与全部互动，在此基础上强化品牌分组和搜索动作，将活动区改为一张游园主推图卡与三张较小的灯谜、寄语和手作卡。中秋 Banner 为 148px，未改回半屏海报。细节见 `第二参考审查_v4.md`。

双击 `index.html` 可离线预览。若需要 HTTP，在本目录运行 `node serve.cjs`，再打开 `http://127.0.0.1:5188`；电脑需已安装 Node.js。也可使用 `启动预览.cmd`。

## 可继续编辑的源码

`home.html`、`style.css`、`portal.css`、`polish-v4.css`、`app.js`、`index.html`、`compare-v4.html`、`assets/`。

`capture-v4.cjs` 为本机尺寸和交互核验脚本，包含当前机器的浏览器路径；移到别的电脑运行需调整路径。PNG 采用 390px 基准画板的三倍导出，使用 9:41 统一比较；交互预览显示当前时间。完整长图将固定底栏放在末尾，实际交互中底栏固定在窗口底部。

## 素材

Banner 使用此前内置 imagegen 生成的 `assets/moon-garden.png`。活动主推图为本轮内置 imagegen 生成的 `assets/lantern-courtyard-v4.png`，属于原创概念场景，不是实际活动或园区实拍。完整提示词和来源记录见 `主视觉生成提示词.md`、`游园场景素材记录_v4.md`。

纸灯、信封、折纸以及礼物造型为可编辑 CSS 内容示意；导航图标为 SVG。字体继续使用 Noto Serif / Noto Sans CJK，附 OFL 许可。

## 交互与核验

保留搜索返回及关键词、活动/礼品收藏、本地安排的加入与取消、签到、灯谜、寄语、弹层关闭和减弱动态适配。签到按上海日期记录；收藏与安排相互独立。

`v4_界面与交互核验.json` 包含八种尺寸、八项入口及主要交互，并新增四张活动卡各自去向的检查；最终素材载入与页面渲染另行复核。`v4_静态扫描.json` 为静态检查。

概念原型没有真实交易、地图定位、报名预约或提醒功能。个人数据只保存在当前浏览器中。未开展真实用户研究或实体手机验证，不能据此宣称使用效率、点击率或满意度提升。

旧版 PNG 与上一级目录中的 v1.0 / v2.0 / v3.0 ZIP 保留，可回溯此前版本。
